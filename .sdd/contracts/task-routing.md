# Task routing

Use installed upstream skills through active runtime's discovery. Read selected skill only when relevant; never preload whole collection. Missing optional skill: report absence, continue authorized SDD workflow under its own contract. Never install or copy a skill merely to satisfy routing.

| Task | Existing helper | SDD boundary |
|---|---|---|
| New feature or integration | `lean-build` | Spec, plan, layer ownership, and completion gates still govern. |
| Unknown failure cause | `investigate-first` | Gather evidence before fixing; investigation alone grants no edit permission. |
| Known bounded defect | `surgical-patch` | Fix responsible layer; preserve requirements and run affected gates. |
| Behavior-preserving restructuring | `safe-refactor` | Establish before/after proof; no silent product changes. |
| Schema, API, configuration, dependency transition | `migration` | Preserve compatibility and rollback; destructive contraction needs existing authorization. |
| Validation or completion proof | `verify-and-stop` | Preserve required gates; no automatic cleanup or repair. |
| Broad repository discovery | Graphify first; `caveman-explore` when useful and delegation permitted | Exact named files need direct reads. No invented exploration capability. |
| Feature review | `theshop-review`; optional `caveman-review` formatting | Keep independent security/quality reviewers and approval-gated fixes. Standalone Cavecrew review never replaces SDD review. |

Explicit workflow wins selection. Helpers refine execution inside that workflow; they cannot switch `theshop-implement` to `theshop-execute`, merge test roles, or auto-invoke explicit-only stages. Unknown cause takes investigation before a patch. Migration risk takes migration guidance even when change is small. Read next helper only when task changes.

Skill names do not prove matching agents are registered. Check live capability before delegation. Preserve SDD specialist names, owned paths, API handoffs, concurrency, retry bounds, and review independence.

Maintenance, memory compression, Cloud setup, discovery telemetry, optimization experiments, and git bookends remain separately requested work. Never route ordinary feature work into those mutations. `caveman-commit` uses project commit format when assisting Ship or a direct message request.

Verify local availability with `pwsh -NoProfile -File .sdd/scripts/check-skill-discovery.ps1`. This checks installed bytes and discovery paths; native selection requires runtime evaluation too.
