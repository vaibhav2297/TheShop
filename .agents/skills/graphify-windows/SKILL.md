# Graphify

When `graphify-out/graph.json` exists, use `graphify query` before broad discovery. Use `graphify path` for relationships and `graphify explain` for focused concepts. Query terms must come from graph vocabulary. Inspect cited source before relying on result.

Run `graphify update .` after code changes. Graph data is derived navigation data, not verification evidence. Do not rebuild or publish graph data unless requested.
